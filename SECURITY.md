# Security Policy

Если вы нашли проблему в областях **security**, **privacy** или **safety**, пожалуйста, не публикуйте чувствительные детали в публичных issue.

## Каналы сообщения

### Предпочтительно (приватно)

Используйте GitHub private vulnerability reporting:

- https://github.com/effexorxruser/Soma/security/advisories/new

### Временный fallback

Если приватный advisory недоступен, создайте issue **без технических деталей уязвимости** с заголовком вида `SECURITY: нужен приватный канал`, и maintainers переведут диалог в приватный формат.

## Что прислать в репорте

- краткое описание;
- шаги воспроизведения (если безопасно);
- ожидаемое и фактическое поведение;
- потенциальное влияние;
- артефакты без персональных данных.

## Scope

Процесс покрывает:

- технические уязвимости в коде/конфигурации;
- privacy-инциденты;
- safety-инциденты (включая обход policy-first contract).

## Что не публиковать в открытом доступе

- PoC/эксплойт-детали до исправления;
- чувствительные данные пользователей;
- инструкции, упрощающие злоупотребление.
