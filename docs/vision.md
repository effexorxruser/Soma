# Vision

## Зачем существует Soma

Soma создается как спокойный, честный и проверяемый foundation для Telegram-first продукта, где безопасность поведения важнее скорости наращивания возможностей.

На раннем этапе цель проста:

- сохранить прозрачные продуктовые границы;
- удерживать policy-first контракт во всех user-facing путях;
- развивать систему через небольшие проверяемые итерации.

## Что для нас «успех»

Успех на текущем этапе — это не «больше фич любой ценой», а:

- предсказуемое поведение в safety-сценариях;
- отсутствие ложной клинической авторитетности;
- ясная документация, совпадающая с реальным состоянием кода.

## Что мы сознательно не делаем

- не имитируем медицинскую/психотерапевтическую помощь;
- не строим маркетинговые обещания вокруг раннего baseline;
- не расширяем scope без подтвержденной надежности текущих инвариантов.
