# Vision

Soma существует как аккуратный foundation-проект для безопасного и честного conversational продукта, начинающегося с policy-first базы.

Ключевая идея: сначала сделать прозрачные границы поведения и проверяемые инварианты, и только потом наращивать функциональность.

Мы не пытаемся «казаться умнее», чем система есть на самом деле. На раннем этапе важнее:

- воспроизводимость поведения;
- прозрачные ограничения;
- спокойный и понятный UX.
