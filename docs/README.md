# Документация Soma

Этот каталог — единая точка входа в документацию проекта.

## 1) Product layer

- [`vision.md`](./vision.md) — зачем существует проект и какой у него реалистичный вектор.
- [`roadmap.md`](./roadmap.md) — стадии развития без раздувания scope.
- [`product-principles.md`](./product-principles.md) — продуктовые инварианты и тон коммуникации.
- [`safety.md`](./safety.md) — явные safety-границы и policy-first требования.

## 2) Engineering layer

- [`architecture.md`](./architecture.md) — текущая архитектурная рамка и контракты между слоями.
- [`development.md`](./development.md) — запуск, env, команды и вклад в код.

## 3) Governance layer (в корне репозитория)

- `CONTRIBUTING.md`
- `SECURITY.md`
- `CODE_OF_CONDUCT.md`
- `LICENSE`

## Scope note

Документация намеренно описывает **только** то, что уже есть в коде, и избегает маркетинговых обещаний.
