# Стартовая архитектурная рамка Soma (MVP-путь)

Документ описывает **начальную** архитектуру репозитория. Это не финальная схема и не признак готового продукта.

## Слои

- **bot layer (`src/bot/`)**  
  Точка входа Telegram-first интерфейса: апдейты, маршрутизация, базовый orchestration входящих событий.

- **core (`src/core/`)**  
  Внутренние правила приложения: базовые сущности, конфигурация, координация модулей.

- **services (`src/services/`)**  
  Прикладные сервисы use-case уровня (поддержка, самоорганизация, контроль границ диалога).

- **integrations (`src/integrations/`)**  
  Адаптеры внешних систем (Telegram API, LLM API, другие провайдеры) — подключаются позже.

- **storage (`src/storage/`)**  
  Интерфейсы и адаптеры хранения данных. На старте слой оставлен пустым по реализации.

- **types (`src/types/`)**  
  Общие TypeScript-типы и контракты для межслойного взаимодействия.

- **tests (`tests/`)**  
  Базовые проверки целостности baseline и будущие unit/integration тесты.

- **docs (`docs/`)**  
  Краткая документация по архитектуре и процессу разработки.

## Почему так

Текущая структура помогает начать MVP без преждевременной инфраструктуры:
- разделены зоны ответственности;
- понятные точки роста для Telegram-first бота;
- нет ложного ощущения, что ключевые интеграции уже готовы.
