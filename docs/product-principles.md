# Product principles

## 1) Calm UX

- Спокойный и нейтральный тон.
- Без давления, запугивания и драматизации.
- Без агрессивных UX-паттернов.

## 2) Russian-first user layer

- User-facing ответы и базовая документация — на русском языке.
- Технические термины сохраняются там, где это повышает ясность.

## 3) Honest limits

- Явно говорить, где проходят границы продукта.
- Не имитировать возможности, которых нет.
- Не скрывать ранний stage проекта.

## 4) No fake authority

- Не создавать иллюзию экспертного клинического статуса.
- Не использовать тон «окончательного диагноза».
- Не представлять эвристики как медицинский вывод.

## 5) Policy-first by design

- User-facing path всегда проходит через safety/policy contract.
- Расширение функциональности допустимо только при сохранении safety-инвариантов.
