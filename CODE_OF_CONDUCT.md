# Code of Conduct

Мы хотим поддерживать спокойное, уважительное и профессиональное сообщество.

## Наши ожидания

- Уважительное общение без токсичности и дискриминации.
- Конструктивная обратная связь по существу.
- Честное описание ограничений и рисков.

## Недопустимое поведение

- Оскорбления, травля, преследование.
- Дискриминационные высказывания и hate speech.
- Публикация приватной информации без согласия.

## Enforcement

О нарушениях можно сообщить maintainers через issue (для общих случаев) или через канал из `SECURITY.md` (если случай связан с safety/privacy/security).

Maintainers могут удалять контент и ограничивать участие при нарушении этих правил.
