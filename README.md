# Soma

Soma — Telegram-first проект бота поддержки и самоорганизации.

На этом этапе в репозитории реализован только **технический baseline**:
- базовая структура папок;
- минимальная настройка Node.js + TypeScript;
- базовые dev-инструменты (lint, format, test);
- шаблонные файлы архитектуры и разработки.

> Важно: здесь **нет** реализованной продуктовой логики, Telegram/OpenAI интеграций, БД и runtime orchestration.

## Что уже есть

- `src/bot/` — будущий слой Telegram surface.
- `src/core/` — базовые внутренние сущности и запуск приложения.
- `src/services/` — будущие прикладные сервисы (поддержка/самоорганизация).
- `src/integrations/` — будущие адаптеры внешних API.
- `src/storage/` — будущий слой хранения данных.
- `src/types/` — общие типы проекта.
- `tests/` — минимальные тесты baseline.
- `docs/` — стартовая документация.

## Быстрый старт

```bash
npm install
```

## Базовые команды

```bash
npm run dev
npm run build
npm run start
npm run lint
npm run format
npm run test
```

## Переменные окружения

Используйте `.env.example` как шаблон и создайте локальный `.env`:

```bash
cp .env.example .env
```

На baseline-этапе переменные заданы как заглушки и не используются интеграциями.

## Логичные следующие шаги

1. Добавить каркас Telegram transport-слоя (без сложной продуктовой логики).
2. Спроектировать базовые domain-модели сценариев поддержки и самоорганизации.
3. Добавить безопасные границы диалога (safety rules) как отдельный модуль core/services.
